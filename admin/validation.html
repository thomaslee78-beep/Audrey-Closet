Manual end-to-end checks

  1. Offline fallback: load Preview while online, enable Airplane Mode / disable network, run Smart Scan and confirm Local Smart Scan opens review without hanging.
  2. Recovery: restore network and run Smart Scan again; confirm Audrey Cloud AI resumes automatically without reload/config changes.
  3. Kill switch: in Admin, temporarily disable AI Smart Scan, run one Preview scan and confirm Local fallback; immediately re-enable AI.
  4. Review/save regression: run a normal AI scan, edit one proposed field, Apply, reopen item and confirm the edited value—not the original proposal—was saved.

The automated suite intentionally does not exhaust quotas or simulate provider charges.
